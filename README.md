# يومي (Android)

تطبيق أندرويد لمتابعة العبادات والمهام. الواجهة صفحة واحدة في `app/src/main/assets/index.html`، والكود الأصلي يضيف التنبيهات والشات.

كل دفع على `main` يبني `yawmi.apk` وينشره في Releases تحت الوسم `latest`.

ملف التوقيع في `signing/` موجود داخل المستودع حتى تبقى التحديثات قابلة للتنصيب فوق بعض، لذلك يجب أن يبقى المستودع خاصًا.
